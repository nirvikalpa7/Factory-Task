Задача про Завод
На заводе есть три категории сотрудников со своими правилами расчёта заработной платы:
1. Рабочий - получает базовый оклад плюс надбавку в размере 10% оклада за каждый полный год работы на заводе, но не более чем 100% оклада (т. е. после 10 лет работы зарплата расти перестаёт).
2. Бригадир - получает базовый оклад плюс надбавку в размере 5% оклада за каждый полный год работы на заводе, но не более чем 40% оклада, плюс 7% суммарной полной зарплаты всех прямых подчинённых.
3. Менеджер - получает базовый оклад плюс 3% суммарной полной зарплаты всех прямых и непрямых (подчинённых подчинённых, подчинённых подчинённых подчинённых и т. д.) подчинённых.
Каждый сотрудник относится к одной из трёх перечисленных категорий. У каждого сотрудника может быть начальник, но только один. Могут также быть сотрудники без начальников. У каждого сотрудника, кроме Рабочего, может быть подчинённый. У Бригадира и Менеджера в подчинении могут быть Рабочие, Бригадиры и Менеджеры. Базовый оклад устанавливается каждому сотруднику персонально в момент найма и в дальнейшем не меняется. Найм всегда производится в первый день месяца, выплата зарплаты - в первый день месяца, следующего за расчётным.
Требуется написать библиотеку типов, которая позволяет рассчитывать за конкретный месяц зарплату каждого сотрудника, а также суммарную заработную плату всех сотрудников (количество денег, которое нужно потратить на выплату всех зарплат). API этой библиотеки должен позволять:
1. Заполнять список сотрудников (с установкой их базовых окладов и дат найма на работу).
2. Назначать сотрудникам подчинённых и начальников.
3. Выполнять расчёт заработной платы каждого сотрудника и суммарно по заводу за конкретный месяц.
Хранение данных в файле или базе данных реализовать не надо, только RAM память. При разработке нужно учитывать, что на заводе могут работать десятки тысяч сотрудников. Решение должно быть написана на современном стандарте языка C++. Разрешено использовать STL. Особое увнимание нужно уделить проектированию красивой иерархии классов, с возможностью использования полиморфизма при необходимости. Должны быть обязательно классы для каждого типа сотрудника и объединяющий класс Завода. Также нужно добавить функцию main где может быть понятный пример использования данного решения. Для имен классов, функций классов, переменных и параметров используй слова из английского языка. Спасибо.
